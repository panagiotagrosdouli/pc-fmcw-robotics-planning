# Claim audit

This document is intentionally conservative. A manuscript claim must not be stronger than the evidence classification below. Raw exploratory p-values are not promoted when the declared multiplicity correction removes confirmatory significance, and repeated grouped split assignments over the same drives are treated as sensitivity analyses rather than independent replication.

| Claim | Status | Evidence / boundary |
|---|---|---|
| Communication-aware motion planning is novel | DO NOT CLAIM | Field is mature since at least 2011. |
| Proactive QoS-risk-map planning is novel | DO NOT CLAIM | Closely overlaps recent communication-aware/radio-map motion-planning work. |
| Optical/FSO/ISAC trajectory planning is novel in general | DO NOT CLAIM | Prior optical ISAC, FSO trajectory-optimization, and visible-light path-planning work exists. |
| CICV5G contains real 5G V2N2V delay plus vehicle/network state | SUPPORTED | 2026 Scientific Data descriptor and public repository. |
| Our real-data framework prevents temporal/run leakage by grouped splitting | SUPPORTED BY CODE | `blocked_run_split`; retain whole-run/route separation in every reported primary experiment. |
| Our framework audits counterfactual spatial support | SUPPORTED BY CODE | Nearest training-measurement distance plus local training density/support diagnostics. |
| Conformal intervals are calibrated event probabilities | DO NOT CLAIM | Implemented residual split-conformal intervals are coverage devices; report empirical coverage, not event-probability calibration. |
| Real V2X data validate PC-FMCW optical communication | DO NOT CLAIM | Different communication technology; the real-data branch validates decision-layer methodology under measured communication conditions only. |
| Real-data planner is real-world autonomous-driving validation | DO NOT CLAIM | Evaluation is route-constrained offline measured replay; future measured QoS is hidden from the planner and revealed only as an outcome. |
| Naive learned spatial/tree predictors beat persistence at one-step delay prediction | NOT SUPPORTED | Persistence is stronger than the tested conditioned spatial kNN / RF / ExtraTrees models on the primary grouped split. Preserve this negative result. |
| Spatial/context information has incremental predictive value at sufficiently long decision horizons | SUPPORTED DESCRIPTIVELY | Horizon-adaptive calibration-gated fusion improves delay MAE versus persistence in all five grouped split assignments at 20/50/100-step horizons. The five assignments reuse the same 38 drives and are therefore robustness/sensitivity evidence, not five independent replicates. |
| Predictive P2 improves measured delay over reactive P1 in the primary replay split | EXPLORATORY | Primary split mean measured-delay delta is about -0.792 ms with a bootstrap interval excluding zero and raw Wilcoxon p=0.046875, but the raw p-value does not survive Holm correction across the 12 replay comparison/metric tests (Holm-adjusted p about 0.28125). Do not call this confirmatory significance. |
| Predictive P2 has a robust favorable measured-delay direction across grouped split assignments | SUPPORTED DESCRIPTIVELY | P2-P1 measured-delay delta is negative in all five precomputed grouped split assignments (mean about -0.501 ms; median about -0.263 ms). These assignments reuse the same drives, so report sign consistency and descriptive ranges only. |
| Predictive P2 robustly reduces the >50 ms violation fraction across grouped split assignments | SUPPORTED DESCRIPTIVELY | P2-P1 violation-fraction effect is negative in all five grouped split assignments (descriptive mean about -0.00224). Do not perform an n=5 inferential test across these reused-drive assignments. |
| Support-aware P3 improves QoS over P2 | NOT SUPPORTED | P3-P2 measured-delay and violation effects are mixed across grouped splits; no stable QoS superiority is established. |
| Support-aware P3 reduces unsupported decision exposure relative to P2 in the primary replay split | EXPLORATORY | Primary split unsupported-fraction delta is about -0.01836 with raw Wilcoxon p=0.03125, but this does not survive the declared Holm correction across the replay family (adjusted p about 0.25). |
| Support-aware P3 robustly reduces unsupported decision exposure across grouped split assignments | SUPPORTED DESCRIPTIVELY | P3-P2 unsupported-fraction delta is negative in all five grouped split assignments (descriptive mean about -0.02795). Interpret P3 as inference-validity/support control with a mobility trade-off, not as an additional QoS-gain planner. |
| Lightweight route-constrained candidate evaluation is computationally practical in the CI implementation | SUPPORTED, IMPLEMENTATION-LEVEL | Vectorized replay implementation shows microsecond-scale batched QoS/support and candidate scoring in hosted CI. Do not generalize this to embedded or end-to-end vehicle real-time capability. |
| The strongest measured-data contribution is support-aware inference validity plus horizon-dependent predictive value, rather than a new radio-map predictor | SUPPORTED BY RESULTS | Persistence is a strong short-horizon baseline; longer-horizon fusion can help, while P3 primarily reduces unsupported decision exposure. |
| V1 PC-FMCW communication outcomes (seeds 1000–1049) are confirmatory | INVALIDATED | V1 failed safety diagnostics (collisions/no-candidate behavior) and had an incomplete frozen endpoint schema. Retain only as historical diagnostic evidence. |
| V2 PC-FMCW communication outcomes are confirmatory | INVALIDATED / DO NOT PROMOTE | The V2 development safety gate did not establish the required safe protocol; communication outcomes cannot be promoted. |
| V3 PC-FMCW development margin, confirmatory communication effects, or geometry-mechanism conclusions are established | NOT TESTED / PENDING FROZEN RUN | Accept only after the predeclared development safety selector passes, fresh seeds 7000–7049 pass the hard safety gate, and the frozen seed-level Holm-corrected analysis completes. Geometry uses fresh seeds 8000–8019 and is a model-mechanism ablation, not physical optical validation. |
| The PC-FMCW robotics link surrogate is experimentally calibrated optical hardware | DO NOT CLAIM | Link parameters are model assumptions/surrogate parameters unless independent calibration evidence is supplied. |
| The upstream nominal 193.4 THz parameter establishes a physically blue headlamp implementation | DO NOT CLAIM | 193.4 THz corresponds approximately to 1550 nm; preserve the provenance inconsistency and do not infer visible-blue photometry, eye safety, detector responsivity, or atmospheric behavior from it. |
