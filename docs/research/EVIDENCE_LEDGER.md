## Update rule

Whenever a new confirmatory artifact is produced, update this ledger before updating manuscript claims. Record the exact run ID, seed range, selected protocol value, artifact name, effect estimate, confidence interval, raw p-value where applicable, Holm-adjusted p-value, and final status. If a hard safety gate fails, mark the associated communication claims **INVALIDATED** rather than attempting post-hoc tuning on reserved confirmatory seeds.
