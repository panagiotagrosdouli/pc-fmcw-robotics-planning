# Methods — real-measurement V2X validation layer

We evaluate a second communication environment independently of the model-based PC-FMCW optical branch. Field-measured 5G vehicle-to-network-to-vehicle (V2N2V) records are used to learn lightweight causal QoS predictors from vehicle state, location, context and recent communication history. The communication measurements are real; the experiment does not relabel 5G measurements as PC-FMCW optical measurements.

To prevent temporal leakage, the unit of partitioning is a complete measurement run rather than an individual timestamp. Whole runs are assigned to training, calibration and test partitions. Model selection includes current-value persistence, spatial KNN, tree ensembles and context-conditioned spatial models. Prediction performance is evaluated on held-out runs using MAE/RMSE and paired run-level effects. Planning-horizon experiments compare persistence with calibration-gated persistence/spatial fusion using only training and calibration runs for fitting and weight selection.

Uncertainty is calibrated on a run-disjoint calibration partition using split-conformal absolute residuals, with additional support-conditioned diagnostics. We report empirical held-out interval coverage and width. These intervals provide marginal empirical coverage under the evaluated split and are not interpreted as calibrated event probabilities.

Empirical validity is audited by fitting a spatial support model exclusively to training coordinates. Each future query reports nearest measured-training distance and local density. Predictions outside a configured support radius/density are flagged. P3 penalizes decisions that rely on poorly supported extrapolation instead of silently treating all map predictions as equally trustworthy.

For decision-value evaluation we use **route-constrained measured-support replay**. At each decision point, P0-P3 choose only among several future states that were actually traversed later on the same held-out measurement run (e.g. alternative look-ahead offsets). All candidates therefore have measured outcome support. Future measured delay is hidden from every planner during scoring and is revealed only after the candidate is selected, where it is used as the evaluation outcome. This design avoids inventing ground-truth QoS for arbitrary off-route counterfactual positions while still testing whether predictive information can change a decision toward a subsequently better measured communication state.

Planner variants are: P0 mobility/reference choice; P1 reactive current-QoS persistence; P2 predictive mean QoS; and P3 predictive QoS plus uncertainty/support penalty. A measured-data oracle P4 is intentionally omitted because observational drive data do not provide ground truth for arbitrary alternative vehicle trajectories.

Primary decision endpoints are run-level mean selected measured delay, selected-state delay-threshold violation fraction, unsupported selected-decision fraction and mobility deviation from the nominal horizon. Secondary endpoints include changed-decision fraction, predictor error, interval coverage/width, SINR diagnostics and measured decision computation time. Statistical inference is performed at the run level with paired bootstrap confidence intervals and paired Wilcoxon signed-rank tests.

A configured 50 ms delay threshold is treated only as an experimental operating point unless a specific application standard is cited. The measured-data layer is offline route-constrained replay: it does not validate arbitrary off-route counterfactuals, PC-FMCW optical propagation, vehicle safety, or real-world closed-loop autonomous-driving operation.
